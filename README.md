## ✨ Overview

**The Warm Mug** is a café website concept focused on combining visual storytelling with a smooth browsing experience. From the first impression to exploring signature drinks and the café atmosphere, every section is designed to feel warm, elegant, and inviting.

The goal is simple: make a local café's online presence feel as memorable as visiting the café itself.

## 🚀 Features

- **Immersive 3D Experience** — Interactive coffee-inspired visuals for a distinctive first impression.
- **Premium UI Design** — Elegant dark theme, warm accents, typography, and polished layouts.
- **Responsive Design** — Adapted for desktop and mobile screens.
- **Menu Exploration** — Browse café offerings with dedicated menu sections and food imagery.
- **Signature Drinks** — Highlighted beverages presented through image-led cards.
- **Visual Gallery** — Showcase the café atmosphere and its signature offerings.
- **Brand Story** — A dedicated section for the café's identity and experience.
- **Customer Reviews** — A section for displaying café reviews.
- **Visit Section** — Location and map integration to help visitors find the café.
- **Order Tray Interface** — An interactive interface for exploring selected items.

## 🎨 Design Philosophy

The design combines a cinematic dark interface with warm café-inspired imagery.

- **Atmosphere first:** Visuals establish the café's personality.
- **Clear navigation:** Visitors can explore the menu, story, gallery, and location.
- **Mobile-first usability:** Layouts are designed to remain usable on smaller screens.
- **Performance awareness:** Production assets are bundled through Vite for deployment.

## ⚙️ Run Locally

### Prerequisites
- Node.js
- npm
- Git

### Installation

```bash
git clone https://github.com/pranjalkumar07/the-warm-mug.git
cd the-warm-mug
npm install
npm run dev
```

Open the local URL shown in your terminal.

### Production Build

```bash
npm run build
npm run preview
```

Vite generates the production build in the `dist/` directory.

## 🌍 Deployment

The project is configured for deployment on Vercel.

1. Import the GitHub repository into Vercel.
2. Use `npm run build` as the build command.
3. Set `dist` as the output directory.
4. Deploy and verify the live experience on desktop and mobile.

**Live website:** Add your deployed Vercel URL above.
